# MOSS 部署说明（Vast 版）

这份是给"租按小时计费的 GPU 跑 MOSS"用的，和长期常驻的算家云部署分开。

## 和常驻部署的区别

| 项 | 常驻（算家云 3090） | 临时（Vast 模板） |
|---|---|---|
| 环境 | 手工装一次，长期跑 | 镜像固定，随开随用 |
| 权重 | 本地磁盘 | 实例盘，销毁即失 |
| 入口 | 反向隧道到橙子 | 同样反向隧道，只是对端换机器 |
| 编排 | 多个 shell 脚本 + supervise | 一个容器，ENTRYPOINT 全包 |

## 大致流程

```bash
# 1. 本地准备镜像（GH Actions 自动构建）
git push origin main        # 触发 build-image，产出 ghcr.io/mcii-deepseek/mcii-moss-image-api:latest

# 2. Vast 建模板（对照 vast/TEMPLATE.md）

# 4. 建隧道回橙子，sub2api 指向橙子对应端口
```

## 首次启动耗时

| 阶段 | 大致时间 |
|---|---|
| 拉镜像 | 5–10 分钟（取决于宿主机带宽） |
| 下权重 17GB | 视带宽，海外通常 2–8 分钟 |
| ComfyUI 加载 + 首个请求 | 1–3 分钟 |

之后停机再开（实例盘还在）只走第 3 步，约 1–2 分钟。

## 成本提醒

Vast 按秒计费，但**停机后存储仍计费**，销毁才停。模型在实例盘上时，
销毁等于重下 17GB，所以要么留实例、要么用同一台机器上的卷。
